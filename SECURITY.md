# Politique de sécurité

## Portée

Ce dépôt contient des documents (classeurs `.xlsx`), des données ouvertes (JSON, CSV), de la documentation et des scripts de validation. Il n'expose aucun service en ligne et ne traite aucune donnée personnelle.

Les points d'attention sont donc :

- un classeur `.xlsx` altéré ou contenant du code exécutable (les classeurs de ce dépôt ne contiennent **aucune macro**) ;
- un lien de téléchargement pointant ailleurs que vers ce dépôt ;
- une dépendance compromise dans les workflows d'intégration continue.

## Signaler une vulnérabilité

Utilisez l'onglet **Security → Report a vulnerability** du dépôt, ou contactez l'Institut du Numérique Responsable via <https://institutnr.org>. N'ouvrez pas d'issue publique pour un problème de sécurité.

Réponse sous 5 jours ouvrés.

## Vérifier l'intégrité d'un classeur

Les classeurs publiés ne contiennent pas de macro. Après téléchargement, votre tableur ne doit proposer aucune activation de contenu. Si c'est le cas, le fichier ne provient pas de ce dépôt : ne l'ouvrez pas et signalez-le.

Source officielle : <https://github.com/Institut-du-Numerique-Responsable/GPC-ONR>
